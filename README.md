# LibTV 工作区（WorkBuddy）

LibTV + wan3.0 视频生产的**工作区沉淀**：平台规范、能力索引、方法论、探测结论与片子记录。

## 这是什么

不是 LibTV 的代码仓库，也不是某个 Agent 框架的源码（那是 `libtv-video-agent`）。
这里是**实操过程中沉淀下来的知识资产**：哪些是平台上实测出来的、哪些是官方文档没写的、
哪些是踩过的坑。目的是换台机器、换个会话，能凭这些材料直接接着干。

## 目录

| 目录 | 内容 |
|---|---|
| `参考文档/` | ★ 核心资产。出片规范、短视频工程规范、平台能力索引、运镜预设、官方与第三方方法论 |
| `报告/` | 平台盘点和选型成果（HTML，自包含） |
| `.workbuddy/memory/` | 工作区记忆：长期档案 `MEMORY.md` + 逐日日志 + 归档 |
| `盗梦空间-落雁桥/` | 成片项目的提示词版本链与生成记录（**仅文本**） |
| `测试-多镜头A组/` | 多镜头测试的 prompt（**仅文本**） |

## 关于素材

**多媒体一律不入库**（见 `.gitignore`）：成片、抽帧、设定图、参考图都留在本地。

原因有三：体积大（几十 MB 到上百 MB）；可再生产；且它们是**逐次生成验证用的素材**，
不是可复用的知识。仓库要留的是「下次怎么做」——规范、判据、坑，而不是「这次做成了什么样」。

`.tmp/` 同理整体排除，它自述「内容随时可清，不含任何资产」，且其下 `mcp_probe/`
落有真实的 OAuth `client_secret` 与 `access_token`。
