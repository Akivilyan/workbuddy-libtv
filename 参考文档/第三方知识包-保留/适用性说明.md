## 二、⚠️ 适用性边界（用前必读）

**保留 ≠ 照抄。** 这份包的写作前提是 **Seedance / StarVideo 2.0 + 黑白九宫格故事板**范式，
而我们 2026-09-23 已改走 **wan3.0 + 多镜头公式**。两者范式不同（见 `..\wan3.0×LibTV-出片规范.md` §6、§7）。

### 逐文件适用性

| 文件 | 可用的部分 | **已作废 / 别照抄的部分** |
|---|---|---|
| `editing-pipeline.md` | ★ **全部可用** —— ffmpeg 本地终剪：xfade 转场链 + offset 公式、音频两路线、封面片头、片尾字幕卡（PIL 中文排版）、嵌缩略图、局部修补、中文路径、拼装自检 | 无（与模型无关，纯 ffmpeg 工程） |
| `content-safety-and-env.md` | ★ **全部可用** —— 审核失败信号分辨、5s 试探片二分排查、真人合规墙与特征文字化、`.ps1` 中文乱码、`Start-Sleep` 拦截、OpenCV 中文路径、EXIF 转正、`PYTHONIOENCODING` | 无（与模型无关） |
| `pitfalls.md` | 抽帧自查工作流、视频内容穿帮排查、角色一致性、环境/编码/文件坑 | 「CLI / 节点操作」节写于 CLI 1.0.2，**以 `libtv --help` 与官方手册为准** |
| `prompt-recipes.md` | 通用铁律：角色一致性、人物比例、正面穷举（排除元素的正确姿势）、数量铁律、防破败滤镜、真人合规边界、一句话原理总表、铁律组合速查 | 「纯黑白铁律」「格内零文字铁律」「九宫格阶段 QC」「clean 喂片版」—— **九宫格故事板专属，我们不用该范式**。且 `{{Image 1}}` 类写法已被 `{{Node …}}` 取代 |
| `production-workflow.md` | 抽帧自查（阶段四）、create-then-verify 防静默失败、批次节奏（阶段五）、单镜 SOP 的报方案与挂图逻辑 | 「黑白素描九宫格故事板」「九宫格重绘对齐」「clean 喂片版」**整条前期链路作废**；CLI 参数以官方手册为准 |
