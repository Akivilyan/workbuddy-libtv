## 1. CLI / 节点操作

| 现象 | 根因 | 解法 |
|---|---|---|
| 旧 `sk-libtv-*` access key + agent-im OpenAPI 调用失败 / 项目不出现在 web dashboard | 旧 OpenAPI 已废弃，且旧 API 建的项目不与 web 账号同源 | **只用 `libtv` CLI**（`libtv login web` 浏览器登录），不要自己拼 HTTP。CLI 建的项目才会出现在 web canvas |
| `node create "<名>"` 同名报错 | create 语义=新建，同名冲突 | 想"存在则更新"用**默认子命令** `libtv node "<名>" ...`（不带 `create`） |
| **`node create` 疑似静默失败**（无报错但节点没建成） | 【历史经验，未重测】后端曾吞请求 | create 后立刻查节点；**只有确认节点不存在**才考虑重新 create，避免把仍在后端执行的任务重复提交 |
| `-u name=` / `-u params=` 被拒写 | `-u` 有白名单：拒 `params/name/label/type/action/taskInfo/prevTaskInfo/generatorType/isStale` | 改展示名用 `--name`；生成器参数用 `-s`；`--prompt` 等价 `-s prompt=` |
| `-s` 写了 schema 外的键被拒 | `-s` 走 schema 校验 | 写前先 `libtv model <modelKey>` 查可用参数 |
| `-s` 和 `-u` 分不清写哪 | 两者落点不同 | 【通用规律】**`-s`→`data.params.*`（生成器参数，走 schema）；`-u`→`data.顶层`（节点自身属性，不影响生成）** |
| `--left` 与 `--left-add/--left-rm` 一起用无效 | 两套改边模式互斥 | 一次只能用一种：整体覆盖用 `--left`，增删用 `--left-add/--left-rm` |
| `group "<名>" --node ...` 不自动建组 | `group <名>` 默认是"操作已有组" | 用 `group create "<名>" --node ...` 显式建组 |
| `script storyboard` 报缺 rows | storyboard 依赖脚本节点已生成 rows | 先 `node "<脚本节点>" --run` 出 rows，再派生 |
| `project list -p` 没列出预期项目 | 不同子命令里 `-p` 语义不同（这里是页码） | 看清上下文：`-p` 在 project list=页码，在 node=项目 ID；项目 ID 不假定是 UUID |
| 并行 `&` 写同一管道 → NDJSON 行串台 | 多进程同时往一个管道写行会撞 | 串行（bash 用 `&&`，PowerShell 顺序执行）；或各写文件再合并。不要 `&` 并行写同管道 |
| `>/dev/null` 用错位置→下游收不到上游 key | NDJSON key 走 stdout，被抑制就断链 | 只在"终点节点 / 不想流到外层管道"时才 `>/dev/null` |
| **`--run` 前台超时，但任务可能仍在后端** | 【2026-08-05 实测】前台调用可超时 | 先查询同名既有节点；确认不存在前不要重新 create |
| **把输入资源误作结果** | 输入与结果都可能出现在节点数据中 | 只消费经检查为 MP4 的结果；不在文档/证据保存远端结果地址 |
| 节点查不到 / 状态查询要轮询 | 【历史经验，未重测】视频作业耗时 | 查询既有节点状态；明确失败前不重复提交 |
| 不能创建 `custom` / `group` / 改节点 `type` | CLI 能力边界 | group 用 `libtv group`；改 type 只能删除重建 |
| `video-clip` 终剪节点没有 model schema | 它靠顶层字段而非生成器参数 | 用 `-u clipTimelineData='[...]'` / `-u content=...` 等顶层字段配置 |

### 后台任务模式（通用模板）

【2026-08-05 实测】前台超时后的安全模式：

```
1. PowerShell run_in_background 提交 node create --run
2. 轮询循环：
   Start-Sleep 30
   → 查同名既有节点状态
   → 节点不存在才决定是否重新 create；节点存在则继续观察，不删除重建
   → 只在结果确认是 MP4 后下载，不记录远端结果地址
   → 审核/真人形象等内容信号停止并走安全排查（见第5节）
```

固定视频参数（试错/定稿两档）：

```
model="StarVideo 2.0"  # 创建用 modelName；先 libtv model star-video2 查询 schema
modeType=image2video
ratio=16:9
resolution=720p   # 【历史经验，未重测】常用试错选择
resolution=1080p  # 【历史经验，未重测】常用定稿选择
duration=8        # 当前 schema 允许 4-15；8 是生产选择
enableSound=off
```

| modeType | 入边 | 用途 |
|---|---|---|
| `text2video` | 仅 prompt | 纯文生 |
| `singleImage2video` | 1 图 | 单图驱动微动作 |
| `frames2video` | 1-2 图 | 首尾帧锁画面 |
| `image2video` | 1-9 图 | 【2026-08-05 实测】多参考主用：clean 故事板→角色→场景→按需道具 |
| `mixed2video` | 1-15 项 | 图+视频+音频混合 |

prompt 用 `{{Image 1}}`/`{{Image 2}}`/`{{Video 1}}` 引用**连线顺序**的第 N 个上游。

## 2. 角色一致性

| 现象 | 根因 | 解法 |
|---|---|---|
| 编辑九宫格不挂角色锚点→角色漂移（案例06长发跑掉） | 【历史经验，未重测】image2image 编辑时模型缺一致性锚 | 【历史经验，未重测】重绘时以角色定版图作外观锚点，原九宫格只取构图 |
| 多参考图里角色服装“渗透”进换装镜头（案例08便装日仍穿校服） | 【历史经验，未重测】角色设定图自带服装，模型连衣服一起抄 | 【历史经验，未重测】“锁脸放衣”：角色定版图只确定脸型发型，衣服完全不按图；正面描述新服装款式并排除原款特征 |
| 特殊着装场景套了角色原服装 / 没穿该有的装备（案例29B水下没装备） | 同上服装渗透 + 缺装备约束 | 写【装备铁律】正面穷举该场景必备装备与姿态（如全程面镜呼吸管脚蹼+漂浮姿态非站立）；服装仍用"设定图只取脸发型、衣服完全不按图" |
| 多角色同框身高乱（应高的不高） | 模型默认均匀身高，无比例锚 | 【通用规律】用**身高对比参考图**作锚 + prompt 写明各角色身高数值与"同框高出一头多"；角色形象本身不变 |
| 男性配角画了清晰脸 / 与主角肢体接触（敏感） | 缺配角处理铁律 | 涉及男性配角=**虚焦/背影/不画清晰脸**，且**绝不与主角肢体接触**（兼顾隐私与审核） |
| 同一道具/数量元素失控（案例：曾出 3 只狗，应 2 只） | **参考图本身是"多姿态拼图"**（10 只狗姿态图）误导模型数量 | 【通用规律】**先查参考图**：数量/实体失控时根因常在参考图含多实例。换"干净的、数量正确的"参考图 + prompt 强约束"总数严格=N，禁第三只/分身" |

【通用规律·设定铁参考】凡画面涉及已定版的角色/场景/道具，**生成必须挂对应定版图作锚点**，绝不只靠文字描述还原设定。当前受控多参考 `image2video` 的槽位按契约安排；其它模式为【历史经验，未重测】。

## 3. 九宫格故事板质量

> 核心定位：**九宫格只承担"这个镜头怎么拍、表达什么"**（构图/景别/运镜/表演），**风格与色彩由设定图 + 质感词承担**。统一画成**黑白素描线稿，不上色**。

| 现象 | 根因 | 解法 |
|---|---|---|
| 重绘人物幼态化/变形/裁掉头/格间漂移（案例13-16） | 小格脸分辨率不够 + 缺比例约束 | 【通用规律】**4K 重绘**（2K 小格脸会糊变形）+ 【人物比例铁律】：写明年龄、成年约 **6.5 头身**、禁儿童幼态、禁大头娃娃、禁裁切头部、五官端正不变形、**9 格同脸同发型同服装**；发型选成年感（高马尾别用丸子头） |
| 挂彩色定版场景图→素描格首末格混入彩色（案例17/18） | 模型把彩色参考的颜色也抄进线稿 | 加【纯黑白铁律】"全部9格（**特别是第1/9格**）纯黑白，彩色参考只取结构转线稿" |
| 格内画了文字（FEE BILL / 消息气泡）→视频照抄穿帮（案例20） | 故事板把文字当画面内容了 | 【通用规律·格内零文字铁律】单据画横线示意、屏幕画亮屏不写字；并在视频 prompt 注明"故事板格号/箭头是标注，不是画面内容" |
| 自我编辑节点先 delete 再 create 同名并 `--left` 引用自身→引用落空，模型凭描述重画（案例18丢后妈） | 删了再建，自引用指向空 | 【通用规律】**编辑已有图必须用新节点名**（如 `_v4`）引用旧节点，成功后再清理旧节点；**本地文件也别覆盖旧版** |
| clean 喂片版逐格没检查→clean 过程偷偷加戏（案例29B格5被画进一只狗，视频忠实照抄） | clean=重绘，重绘可能产生幻觉加内容 | 【通用规律】**clean 版也要逐格 QC**；穿帮反复出现时**先查所有参考图里有没有那个元素**，再怪 prompt |

### clean 喂片版（去格号）标准做法

九宫格左上角**格号数字 / 箭头标注**会被视频照抄进画面（案例19淡/22明显/27气球上"②"）。三层防御：

1. 视频 prompt 用【绝对零文字零数字】铁律。
2. 仍穿帮时**不重抽**：用 image2image 把九宫格"去掉所有格号箭头、其他不变"做成 `sb_XX_clean` 喂片版再生成。
3. **重要镜头（高潮戏）直接用 clean 版**起步。
4. clean 后**逐格 QC**（见上条，clean 会幻觉加戏）。

## 4. 视频内容穿帮

| 现象 | 根因 | 解法 |
|---|---|---|
| **负面词反而召唤实体**（案例29B"禁止出现狗"连续3版都画出狗） | Seedance 负面指令弱，提到名字=激活概念（"别想大象"效应） | 【通用规律】**排除某元素时通篇不提它的名字**，改用【画面元素铁律】**正面穷举**"画面里有且只有：…"。需要硬负面时也尽量配正面穷举 |
| 挂定版场景图→视频变"环境展示片"，不按分镜人物表演（案例17） | 场景参考喧宾夺主，模型去拍空镜 | 加【镜头铁律】"九宫格是唯一拍摄脚本、镜头始终以人为主体紧跟不离开、**禁止长段空镜/环境展示运镜**、场景只是背景" |
| 道具定版图喂作 5 参考之一→视频自由发挥（案例30蛋糕变圆蛋糕+乱加顶饰） | 独立道具图=模型"凭图重摆"，自由度太大 | 【通用规律·in-scene 锚定法】用"道具已摆在场景里"的**合成图**（如 cake_in_living）替代独立道具图作参考，prompt 写"和图中XX上的道具一模一样" —— **照抄在场比凭图重摆可靠** |
| 长镜头后半段房间/场景漂移（案例02在9s后客厅变样板房） | 时间越长越偏离参考 | 【通用规律】加【场景锁定铁律】"全程同一房间、家具布局严格按场景图保持不变、禁止切换房间/家具消失"；**长镜头缩到 12s 以内**降漂移 |
| "农村/砖房/90年代"词触发模型**破败滤镜**（案例05墙皮脱落两连） | 贫穷联想词激活破败质感 | 【通用规律】**删掉所有会联想贫穷的词**，只正面描述"被好好打理的温馨家"（白墙/清漆木柜/挂历相框/台灯）+ 硬负面"绝对禁止墙皮脱落裸砖污渍裂缝"；夜晚氛围只靠光线表达 |
| 视频内容重复（来回同一动作） | 动作单一 + 时长过长 | 缩短时长 / 让 9 格各有动作推进，不来回 |
| 单镜各自"广角收死"→镜头间融不起来 | 每镜独立构图无衔接 | 段内镜头**结尾留转场钩子**（给光/门/手出口）；靠剪辑转场+配乐+旁白融合 |
| 道具风格与场景不搭（案例：3D 蛋糕配 2D 场景） | 道具与场景分开生成 | 全片定同一风格；道具与场景**同一次生成**，不分开做再贴 |
| 故事板里的礼物盒被视频变成"木盒+蛋糕突变" | 故事板道具与目标不一致 | 重绘九宫格（让目标道具成焦点）+ 首帧锁定正确道具在位 |
| 凭脚本推测含真实记忆的镜头细节会错（案例28领证构图/29A谁接戒指/30蛋糕样式） | 真实仪式/道具有客观事实，瞎猜必错 | 【通用规律】**含真实仪式/道具/人物关系的镜头，先问用户拿真实参照（照片/口述）再设计九宫格**，不按旧剧本文字加戏 |
| Seedance 偶发后端“生成超时”失败（画布红字） | 【历史经验，未重测】临时负载 | 先查询既有节点并分类原因；确认终态失败后再人工决定是否重做 |

【通用规律·忠于故事板】每镜挂哪些角色/场景/道具参考，由该镜九宫格**实际画面内容**决定，不按旧剧本文字加戏。

### 视频生成后必做：抽帧自查工作流

【通用规律】每条视频生成后，用 ffmpeg 抽 4-10 帧拼成对照图，Read 该图**自查**后才报用户：

- 角色一致（脸/发型/服装跨帧不变）
- 人物比例（无幼态/无变形/无裁头）
- 无穿帮（无格号数字/无多余实体/无文字）
- 关键数量元素正确（如狗=2）
- 服装符合该镜（换装镜没渗透原服装）
- 场景未漂移

自查不过→定位是 prompt 问题还是参考图问题（先查参考图），改了重生成。

## 5. 安全审核与真人形象

| 现象 | 根因 | 解法 |
|---|---|---|
| 视频报“**输入内容未通过安全审核**”（案例30三连拒） | 【历史经验，未重测】某张参考图或某格构图被误判 | 【历史经验，未重测】用短时探针 + 参考图二分定位真凶；退款/积分以平台可见确认结果为准。人+宠物贴脸大特写慎用 |
| 视频报"**参考图可能包含真人形象，请先合规校验**" | Seedance 对含真人形象的参考图硬拦，**连 CG 化/裁剪都拦不住** | 【通用规律·真人合规墙】两条路：① 走平台官方**真人形象授权校验**（网页端）后再用该图；② **纯文字描述长相**（不挂真人图）可绕过，但相似度打折。不要指望靠 P 图骗过审核 |

【历史经验，未重测】涉及男性配角虚焦/背影/不接触主角，既是隐私也是降低审核风险的措施（见第2节）。审核失败的退款/积分变化须以平台可见记录确认。

## 6. 剪辑 / 音频

| 现象 | 根因 | 解法 |
|---|---|---|
| 音乐生成节点 create 报"场景不一致" | 音频节点默认 TTS 场景，音乐模型需另一场景 | 【通用规律】音乐模型（vocal-music / mureka-8 等）create 必须加 **`-s scene=Music`** |
| 片源实际带有音轨 | 【历史经验，未重测】可作为可用素材 | 可让 `acrossfade` 随 `xfade` 同步交叉；不要假定 `enableSound=off` 仍会生成环境音轨 |
| 拼片脚本手写镜头序列易笔误（案例：漏15、重复16） | 手写序列易错 | 【通用规律】拼装后**必须核对 clips 数与序号连续性**；成片时长和预估对不上要回查 |
| 转场点对不齐 / 累积偏移 | AAC 编码每段前后有 priming/padding 静音，多段拼接逐段累积，导致 xfade 偏移 | 【通用规律】**AAC padding 累积**：转场偏移时改用音频 acrossfade 与画面 xfade 同步，或拼接前统一转无 padding 中间格式（如 wav / 重新封装），避免逐段累积静音 |

【通用规律·转场母题】统一剪辑靠**转场（光/门/手等母题）+ 连续配乐 + 第一人称旁白 + 字幕**把各自独立的单镜融合成片；每段镜头结尾留好转场钩子。

## 7. 环境 / 编码 / 文件

| 现象 | 根因 | 解法 |
|---|---|---|
| `.ps1` 文件里的中文 prompt 被 GBK 读成乱码 | PowerShell 脚本文件默认编码坑 | 【通用规律】中文 prompt **用内联 PowerShell**，不写成 `.ps1` 文件 |
| PowerShell 输出中文乱码 | 调用其他 Python 工具时编码未设 | `$env:PYTHONIOENCODING = "utf-8"`（libtv CLI 内部多已处理，调外部 Python 工具时仍需） |
| `cv2.imread` 读不了中文路径（返回 None） | OpenCV 不支持中文路径直读 | 【通用规律】读：`cv2.imdecode(np.fromfile(p, dtype=np.uint8), 1)`；写：`cv2.imencode(...)` 后 `.tofile(p)` |
| 中文 Windows 路径在 bash 里列文件报错 | bash 对中文路径处理差 | 文件操作用 PowerShell / 专用工具，不用 bash 的 `ls` |
| 对话框附件 Agent 读不到磁盘字节 | 附件不落本地磁盘 | 让用户把文件**存到项目目录给绝对路径**，libtv 才能 `upload` |

## 附：贯穿全流程的硬约束（违反=返工）

1. **风格基调固定**：一套质感词从头用到尾（本项目=2D柔和绘本动画插画），明确写死"绝不要"的反面词（3D渲染/C4D/Octane/写实立体/照片真实感）。
2. **生成视频前必须先报方案、得到用户"可以/OK"才 `--run`**；图片（用户明确要的道具/首帧）可直接做。
3. **批次节奏铁律**：每批 3-5 镜，**逐镜让用户确认**，绝不擅自批量触发视频。
4. **忠于故事板**：参考挂载由九宫格实际画面决定，不按旧剧本文字加戏。
5. **数量铁律**：关键可数实体（如狗=2）用干净参考图 + prompt 强约束总数。
6. **设定铁参考**：涉及定版角色/场景/道具必挂定版图，不靠文字还原；当前多参考 `image2video` 按槽位契约安排。
7. **九宫格=黑白素描线稿不上色**：只管"怎么拍"，风格色彩交给设定图+质感词。
8. **含真实记忆的镜头先拿真实参照再设计**。

## 核心管线一图流（通用）

```
黑白素描九宫格故事板(9格, 用户/AI画)
   │  ← 缺锚/漂移时
▼  nebula-ultra image2image 重绘（【历史经验，未重测】挂角色定版图作外观锚点 + 原九宫格作构图，4K）
重绘九宫格
   │  ← 有格号/箭头/彩色时
   ▼  生成 clean 喂片版(去格号数字/箭头/彩色, 纯黑白线稿) + 逐格 QC
clean 九宫格
   │
   ▼  StarVideo 2.0 image2video（按契约挂 clean九宫格→角色→场景→道具，2D质感词，
      720p 试错/1080p 定稿为【历史经验，未重测】；报方案求确认→查询既有节点）
彩色单镜视频
   │  ← 抽帧自查(一致性/比例/穿帮/数量/服装/场景)过了才报用户
   ▼  ffmpeg 统一剪辑(转场母题 + 连续配乐 + 旁白 + 字幕; acrossfade同步xfade)
成片
```
