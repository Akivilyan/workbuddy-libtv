# Prompt 铁律模板库（LibTV / StarVideo / Seedance 通用）

> 跨项目通用的 **prompt 片段库**。每条把一类反复踩到的坑抽象成「可复制即贴」的铁律，给出：**何时用 / 模板原文 / 原理**。
> 适用于 LibTV CLI（图片 `nebula-ultra` / `seedream-4`，视频 `star-video2`，当前 modelName 为 `StarVideo 2.0`）的图片编辑、九宫格重绘、视频生成三类任务。
> 案例标注「案例」二字均来自某 30 镜短片项目，仅作举例，方法论本身与项目无关。

> **2026-08 v2 边界**：当前受控多参考 `image2video` 只按 [AGENTS.md 槽位契约](../AGENTS.md#32-参考图槽位契约唯一准则)解释为 clean 故事板→角色定版→场景定版→按需道具；schema 的图像数量和证据范围见[能力快照](capability-snapshot-2026-08-05.md)。本文件的模型行为配方是【历史经验，未重测】，不可把角色槽位外推为“永远第一张”。

---

## 0. 使用总则（读模板前先懂这 5 条）

1. **Seedance / 多图参考模型「忠实照抄参考图」**：参考图里有什么，视频大概率就有什么。所以**约束顺序 = 先管参考图，再管 prompt**。穿帮反复出现时，第一步永远是「去所有参考图里找那个穿帮元素」，而不是改 prompt 措辞。
2. **负面指令很弱（"别想大象"效应）**：模型对「禁止/不要/没有 X」响应差，甚至 prompt 里出现 X 的名字反而召唤它。**排除元素的正确姿势 = 正面穷举（见 §6），通篇不提它的名字。**
3. **参考图分工要显式声明**：一张图可能既想取「脸/发型」又不想取「衣服/姿势」。必须在 prompt 里按语义角色写清「角色定版图只用来确定 ___，其他不按图」（见 §10、§11）；当前多参考图位按槽位契约映射。
4. **风格/色彩由「设定图 + 质感词」承担，构图/表演由「九宫格」承担**。两者不要混：九宫格是黑白线稿脚本（怎么拍），设定图 + 质感词决定最终长相和画风（见 §13）。
5. **铁律写法**：用「【XX铁律】」做显式标题段落，正向描述 + 必要的硬负面。把最关键的约束放 prompt 靠前位置。涉及人物的镜头，**至少叠**【角色铁律】+【人物比例铁律】两条。

模板里的占位符约定：`X` = 序号 / 数量；`【】` 标题原样保留；`<…>` 替换为具体内容。

## 1. 【角色铁律】——锁同一个人

**何时用**：任何含角色的图片/视频。九宫格重绘（9 格同一人）、多镜头跨段（同角色不漂移）、挂角色定版图做一致性时。这是含人镜头的**默认必带项**。

**模板原文**：
```
【角色铁律】严格按角色定版图还原人物：9格/全程同一张脸、同一发型、同一服装、同一年龄段。
五官、脸型、发型、发色、肤色完全一致，不允许格与格之间、镜头与镜头之间出现长相漂移、换脸、换发型。
角色定版图是唯一外貌依据，文字描述只补充表情和动作，不改变长相。
```

**原理**：【历史经验，未重测】多图参考时，文字之外仍需角色定版图作为外观锚点；在当前受控多参考 `image2video` 中，它是第 2 槽，模板不把这一位置外推到其他模式。
- 案例：【历史经验，未重测】九宫格只挂构图不挂角色锚点 → 第 6 格人物长发漂移；后以角色定版图作外观锚点、原九宫格只取构图并加本铁律后稳定。

## 2. 【人物比例铁律】——禁幼态/大头娃娃/裁头/变形

**何时用**：九宫格小格重绘、多人物镜头、任何出现过「人物显小/显嫩/脸糊/头被裁/比例怪」的场景。与【角色铁律】配套叠用。

**模板原文**：
```
【人物比例铁律】人物为<具体年龄，如27岁成年女性>，成年身材比例约6.5头身，肩宽腿长符合成年人。
严禁儿童幼态、娃娃脸、Q版、大头娃娃、头身比失调；严禁把头部裁切出画（每格人物头部完整在画面内）。
五官端正、左右对称、不变形、不糊；发型选符合该年龄的成熟款式（如<高马尾>，不用<丸子头等显幼款>）。
```

**原理**：小格（尤其 2K 分辨率）模型会把脸画糊、自动「卡通幼态化」、为塞进格子裁掉头部。对策三件套：
- **提分辨率到 4K**（2K 小格脸必糊变形）——这是参数层，不是 prompt 层，但必须同时做；
- prompt **显式写年龄 + 头身比 + 禁幼态 + 禁裁头**；
- **发型选「成年感」款**（高马尾优于丸子头）。
- 案例：13–16 镜九宫格重绘连续幼态化/变形/裁头/格间漂移，三件套齐上才修好。

## 3. 【纯黑白铁律】——九宫格全程不上色

**何时用**：重绘黑白素描九宫格故事板，且**挂了彩色定版图作参考**（结构准但会把颜色带进来）时。第 1 格、第 9 格最容易混入彩色。

**模板原文**：
```
【纯黑白铁律】输出为纯黑白铅笔素描线稿，全部9格（特别是第1格和第9格）一律纯黑白，无任何彩色、无平涂上色、无水彩。
所挂彩色参考图只用来取构图结构和场景布局，把它转成黑白线稿，绝对不要保留它的颜色。
整图风格统一为铅笔素描，线条干净。
```

**原理**：彩色参考图的颜色会「渗透」进本应是线稿的输出，且首末格最常出事。**显式声明彩色图只取结构、转线稿、丢颜色**，并点名第 1/9 格强调。
- 案例：17/18 镜挂彩色定版场景图，重绘出的素描格首末格混入彩色，加本铁律后纯黑白。
- 配套理念：九宫格只承担「怎么拍」，色彩交给最终出片阶段的设定图 + 质感词（见 §13），所以九宫格保持黑白是正确分工。

## 4. 【格内零文字铁律】——九宫格阶段不画任何字

**何时用**：画/重绘九宫格故事板时，镜头里有单据、屏幕、招牌、手机、聊天框等「本该有字」的元素。**这是预防针，在素材源头堵字。**

**模板原文**：
```
【格内零文字铁律】九宫格任何一格内都不要写任何真实文字、数字、字母、招牌字、单据字、聊天气泡字。
需要表示"有字的东西"时用示意画法：单据画几条横线代表文字行；屏幕/手机画成发光的亮屏不写内容；招牌画空白牌子。
另：格子外的格号、序号、箭头、标注是给人看的拍摄标注，不是画面内容，生成时必须忽略、不得画进任何一格。
```

**原理**：九宫格里只要画了具体文字，下游 Seedance 会**忠实照抄**进视频造成穿帮（错别字、乱码、不该出现的内容）。源头用「横线/亮屏/空白牌」示意，既表达了「这里有字」又不留具体内容。**格号/箭头属于标注层，必须声明忽略**，否则会被当画面内容画出来。
- 案例：20 镜九宫格里画了「FEE BILL」单据字、消息气泡字，视频照抄穿帮 → 改横线示意 + 亮屏不写字。

## 5. 【绝对零文字零数字】——视频生成阶段（最强版）

**何时用**：**视频 image2video / text2video 的 prompt 里**，尤其是参考图（九宫格、场景图）角落带格号数字、或镜头本身有屏幕/单据。这是 §4 的下游加强版。

**模板原文**：
```
【绝对零文字零数字铁律】成片画面的任何角落、任何物体表面，都不允许出现数字、文字、字母、符号、水印、字幕、格号。
所挂参考图（九宫格/草图）四角或格子里若带有格号数字、箭头、标注，那些是制作标注，不是画面内容，必须完全忽略、绝不渲染进视频。
画面中的屏幕一律是纯发光亮屏、单据一律是空白或只有横线示意，不出现任何可读字符。
```

**原理**：九宫格左上角的格号数字（"①②③"）会被视频「照抄进画面」（轻则隐约、重则明显，甚至贴在道具上）。
- **首选**：用本铁律在视频 prompt 里声明忽略。
- **顽固穿帮（重要镜头）的兜底**：不要反复重抽，改用 **clean 喂片版**——`nebula-ultra` image2image 把九宫格「去掉所有格号/箭头/多余标注、其他完全不变」生成 `sb_XX_clean`，再拿 clean 版喂视频（案例 27 镜验证有效）。高潮戏直接上 clean 版省事。
- ⚠️ **clean 版也要逐格 QC**：clean = 重绘，可能顺手加戏（见 §7）。

## 6. 【画面元素铁律 / 正面穷举】——排除元素的正确姿势

**何时用**：要让画面**不出现**某元素（多余的狗、第三个人、某道具），而**负面词「禁止出现 X」反复失效甚至越禁越多**时。这是处理「鬼影元素」的核心方法。

**模板原文**：
```
【画面元素铁律】这一镜画面里有且只有以下元素：<元素A>、<元素B>、<元素C>、<背景D>。
除上述之外不出现任何其他生物、人物、动物或道具，构图干净、主体明确。
（通篇不再提及不想要的那个元素的名字。）
```

**原理**：Seedance 负面指令弱，且 prompt 里一旦出现「禁止出现狗」里的「狗」字，反而把狗召唤出来（"别想大象"效应）。**正确做法 = 通篇不提那个名字，改成正面穷举「画面里有且只有 …」**，用白名单把空间占满，没给它位置。
- 案例：29B 水下镜「禁止出现狗」连续 3 版都画出狗；改用正面穷举「画面里有且只有：女主穿全套潜水装、漂浮、蓝色海水、珊瑚」后消失。

## 7. clean 版/重绘版必逐格 QC（方法，非 prompt 片段）

**何时用**：每次用 `nebula-ultra` 重绘九宫格或做 clean 喂片版之后，喂给视频**之前**。

**做法**：
```
重绘/clean 完成 → 逐格 Read 检查 → 确认没有「多出来的元素」（多一只狗、多一个人、凭空加的道具）→ 才喂视频。
穿帮反复出现且改 prompt 无效时，第一嫌疑是「参考图/clean 版里本身就画了那个元素」，先查图再怪 prompt。
```

**原理**：clean / 重绘本质是「重新画一遍」，模型可能顺手加戏；下游视频会忠实照抄这个加戏。
- 案例：29B 顽固穿帮连改 4 版都在 → 真凶是 clean 过程在第 5 格画进了一只狗，视频照抄。**clean ≠ 无损去标注，clean = 重绘，必 QC。**

## 8. 【镜头铁律】——镜头跟人，不要变环境展示片

**何时用**：视频 prompt，尤其**挂了彩色定版场景图**时（模型容易被场景吸引，跑去做空镜环境展示而不演人）。

**模板原文**：
```
【镜头铁律】九宫格是这一镜唯一的拍摄脚本，必须严格按九宫格的人物动作和分镜表演来拍。
镜头始终以人物为主体、紧跟人物不离开；禁止长段空镜、禁止环境展示式运镜（缓慢扫场景/扫天花板/扫家具）。
场景只是人物活动的背景，不是主角，不要为了展示场景而让人物离开画面。
```

**原理**：挂了漂亮的场景定版图，模型倾向于「炫场景」——大段空镜、环境平移，把人物丢一边，导致镜头不按分镜表演。本铁律把「人是主体、场景是背景、九宫格是唯一脚本」说死。
- 案例：17 镜挂定版场景图后变成环境展示片，不按分镜人物表演；加本铁律后回到以人为主。

## 9. 【场景锁定铁律】——长镜头房间/家具不漂移

**何时用**：较长镜头（尤其 >9s）且同一室内空间，出现过「拍着拍着房间变样、家具消失/换布局」时。

**模板原文**：
```
【场景锁定铁律】全程为同一个房间、同一套家具和布局，严格按场景参考图保持不变。
镜头移动时家具的相对位置、墙面、门窗、陈设都不改变；禁止中途切换到另一个房间、禁止家具凭空消失或新增、禁止变成样板房/展厅。
```
**配套参数**：长镜头**缩到 12s 以内**（最好 8–10s）以降低漂移概率。

**原理**：时长越长，模型越容易在后半段「重新发挥」把房间画成另一个样子。prompt 锁布局 + 缩短时长双管齐下。
- 案例：02 镜 15s 长镜头在 9s 后客厅变样板房；加锁定铁律 + 缩到 12s 内后稳定。

## 10. 【装备铁律】——特殊着装全程不掉

**何时用**：潜水/滑雪/骑行/防护服等**特殊着装**镜头，出现过「装备时有时无、变回常服、姿态不对」时。

**模板原文**：
```
【装备铁律】人物全程穿戴完整的<潜水>装备：<面镜、呼吸管、脚蹼、潜水服>一件不少，从头到尾不脱不换不消失。
姿态符合该场景物理：<在水中为漂浮/划水姿态，不是站立>。
（最可靠做法：把这套装备直接画进九宫格线稿里锁死，比只在文字里描述更稳。）
```

**原理**：特殊装备模型容易「半路忘穿」或姿态错（水下却站立）。文字约束之外，**把装备画进九宫格线稿是最强锁定**——视频会照抄线稿里的装备。
- 案例：29B 水下镜凭空缺装备/姿态站立；写全装备铁律 + 漂浮姿态后修复。注意服装渗透问题另见 §11。

## 11. 【服装渗透解法】——换装镜头不被定版服装带跑

**何时用**：角色定版图穿 A 套衣服，但本镜要换成 B 套（换装日、不同人生阶段、特殊场合），结果视频还是穿回 A 套时。

**模板原文**：
```
角色定版图只用来确定脸型、五官、发型、发色，衣服完全不按这张图。
本镜服装为：<正面详细描述新款，如 浅色棉质连衣裙、圆领、无拉链、无条纹>。
画面中人物不穿<原款特征，如 校服 / 运动服 / 拉链外套 / 条纹>。
```

**原理**：角色定版图的服装会「渗透」进换装镜头。三段式解法：
1. **显式拆分参考图用途**：第 X 图只取脸/发型，衣服不按图；
2. **正面详细描述新款**（给模型明确目标，别只说"换衣服"）；
3. **负面排除原款的标志性特征**（无拉链/无条纹/非运动服）。
- 案例：08 镜女主便装日仍穿校服 → 三段式解法后换装成功。

## 12. 【in-scene 锚定法】——道具用「已摆在场景里」的合成图

**何时用**：有定版道具（蛋糕、特定造型物），把它当 5 张参考之一喂视频，结果视频**自由发挥**（道具走样、变普通款、加奇怪装饰）时。

**模板原文**：
```
参考做法：不要用「道具单独一张图」作参考，改用「道具已经摆在场景里」的合成图（如 桌上已放好该蛋糕的客厅图）作参考。
prompt 写：和图中<茶几上的那个蛋糕>一模一样，<蛋糕本身就是房子的造型>，位置、样式、大小都照图不变，不要重新设计、不要改成普通<圆蛋糕>。
```

**原理**：独立道具图 → 模型理解成「这是个素材，我来重新摆/重新设计」；**已在场景里的合成图 → 模型理解成「照抄这个既成画面」**，照抄比凭图重摆可靠得多。先用图片模型把道具合成进场景，再拿合成图喂视频。
- 案例：30 镜蛋糕（房子造型）当独立参考喂进去变成圆蛋糕+房顶装饰；改用 `cake_in_living` 在场合成图 + 「和图中茶几上的蛋糕一模一样、蛋糕本身就是房子」后照抄正确。

## 13. 质感词两套（2D 绘本 / 写实）

**何时用**：每条出片（图片或视频）的 prompt **结尾固定追加**一套质感词，决定整片画风。**全片只选一套并贯穿始终**，不要混。九宫格阶段不需要质感词（黑白线稿），出片阶段才加。

**A. 2D 柔和绘本动画**：
```
2D柔和动画绘本插画风格，柔和干净的线条，温暖平涂上色，绘本质感，温暖自然光，gentle 2D storybook animation；
绝不要3D渲染、绝不要C4D/Octane、绝不要写实立体、绝不要照片真实感。
```

**B. 写实电影感**：
```
照片级真实感，真实光影、真实皮肤与毛发质感、自然肤色，浅景深，电影级打光，cinematic photoreal；
绝不要动画、绝不要卡通、绝不要2D插画、绝不要绘本平涂。
```

**原理**：风格不靠运气，靠**固定质感词 + 固定基调**。两套互为硬负面（2D 排斥写实，写实排斥 2D），把对立面写进负面防止跑偏。**关键：风格由质感词 + 设定图承担，构图/表演由九宫格承担**——所以九宫格保持黑白线稿（§3），出片才加质感词。
- 案例：项目最初要 3D/C4D/Octane，后全面改 2D；A 套即该片固定质感词。

## 14. 配角铁律——男性/陌生人虚化、绝不接触主角

**何时用**：画面需要出现男性配角、路人、陌生人，但**不希望喧宾夺主、也涉及合规/隐私/真实人物敏感**时。

**模板原文**：
```
【配角铁律】画面中的<男性配角/陌生人>一律虚焦处理：用背影、侧影、模糊虚化、半身带过，不刻画清晰的脸和五官。
该配角与主角之间始终保持身体距离，绝不发生任何肢体接触（不牵手、不搂抱、不搭肩、不贴身）。
主角始终是画面焦点，配角只是环境的一部分。
```

**原理**：清晰刻画的配角会抢焦点、且更容易触发「真人形象 / 亲密接触」类敏感判定。**虚焦 + 背影 + 零接触**既保主角焦点又规避风险。
- 案例：涉及男性配角的镜头统一虚焦/背影/不画清晰脸，且绝不与主角肢体接触。

## 15. 数量铁律（狗/人/任何可数实体）

**何时用**：画面有**固定数量**的可数实体（N 只宠物、N 个人），出现过「多一只 / 分身 / 鬼影」时。与 §6 正面穷举常配合。

**模板原文**：
```
【数量铁律】画面中的<狗>总数严格等于<2>只，分别是：<狗A=棕红色大狗戴绿背带>、<狗B=白色小狗戴蓝背带>。
不允许出现第<3>只、不允许分身、不允许背景里多出同类。
（参考图请用「干净的恰好N只」的图，不要用「多姿态拼图/多个体合集」的设定图。）
```

**原理**：两层防多：
1. **参考图层**：用「干净的恰好 N 只」参考图，**绝不用多姿态拼图/多个体合集**（那种图本身就在暗示「这里有很多只」）；
2. **prompt 层**：写死总数 = N、逐一点名特征、禁第 N+1 只/分身。
- 案例：曾用「10 只狗姿态拼图」设定图导致视频出 3 只狗；换 `dogs_clean`（干净双狗）+ 「狗总数严格=2，禁第三只/分身」后修复。

## 16. 真人照片合规墙（重要边界，非 prompt 可绕）

**何时用**：任何想把**真人照片**（或其 CG 化/裁剪版）当参考图喂 **Seedance 视频模型**时。

**现象**：视频模型对「含真人形象的参考图」会拒，报「参考图可能包含真人形象，请先合规校验」。**连 CG 化、裁剪都拦不住**——这是合规闸门，不是 prompt 能绕过的。

**解法**：
| 路径 | 做法 | 代价 |
|---|---|---|
| 官方授权（正路） | 走平台网页端的**真人形象授权/合规校验**流程，验证通过后该形象可用 | 需网页端操作、需本人授权 |
| 纯文字描述（绕行） | **不挂真人图**，纯文字描述长相（脸型/发型/气质/年龄） | 相似度打折，做不到精准还原 |

**原理**：合规墙在模型入口，prompt 改写无效。**含真实人物的镜头要么走官方授权，要么接受「文字描述 + 相似度打折」。** 内容安全审核（"输入内容未通过安全审核"）是另一回事，用 5s 试探片 + 参考图二分法定位真凶（如「人脸贴宠物」大特写易被误判，改中景即过）。

## 17. 防贫穷/破败滤镜（环境词陷阱）

**何时用**：场景设定涉及「农村 / 老房子 / 90 年代 / 砖房 / 老家」等词，结果模型自动加「墙皮脱落、裸砖、污渍、破败」滤镜时。

**模板原文**：
```
删掉所有会联想到贫穷/破败的词（不写"农村/砖房/老破/90年代/简陋"）。
只正面描述一个被好好打理的温馨的家：<干净的白墙、清漆木柜、墙上挂历和相框、暖色台灯、整洁地面>。
硬负面：绝对禁止墙皮脱落、禁止裸露砖墙、禁止污渍、禁止裂缝、禁止破败感。
年代/夜晚氛围只用光线和陈设表达，不用会触发破败的词。
```

**原理**：「农村/砖房/90 年代」这类词会触发模型的「贫穷破败」联想滤镜。对策同 §6 思路——**删掉触发词，正面描述「被打理好的温馨家」**，再加硬负面兜底。氛围（年代感、夜晚）改用光线和具体陈设表达。
- 案例：05 镜「农村/砖房/90 年代」连续两版墙皮脱落裸砖；删词 + 正面温馨描述 + 硬负面后修好。

## 19. 一句话原理总表（背下这些就够）

| 铁律 | 一句话原理 |
|---|---|
| 角色 / 比例 | 【历史经验，未重测】给角色定版图作外观锚点；具体槽位遵循当前契约，不假定永远第一 |
| 纯黑白 | 彩色参考会渗色，显式声明「只取结构转线稿」 |
| 格内零文字 / 零文字数字 | 九宫格画了字，视频照抄；源头用横线/亮屏示意，格号是标注要忽略 |
| 正面穷举 | 负面指令弱，提名字反召唤；改写「有且只有 …」 |
| 镜头 | 挂场景图易变环境展示片；声明「人是主体、场景是背景」 |
| 场景锁定 | 长镜头后半段会漂移；锁布局 + 缩到 12s 内 |
| 装备 | 把装备画进九宫格比文字更稳 |
| 服装渗透 | 拆分参考图用途「只取脸发型」+ 正面描新款 + 负面排原款 |
| in-scene 锚定 | 「已在场景里」照抄 > 「独立道具图」重摆 |
| 质感词 | 风格靠固定词 + 设定图，不靠运气；两套互为硬负面 |
| 配角 | 虚焦/背影/零接触，既保焦点又避敏感 |
| 数量 | 参考图用「恰好N只干净图」+ prompt 写死总数禁分身 |
| 真人合规墙 | 模型入口闸门，prompt 绕不过，走授权或文字描述 |
| 防破败 | 删贫穷触发词，正面描温馨家 + 硬负面 |
