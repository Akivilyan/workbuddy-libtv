    Alibaba Cloud Model Studio：文生視頻/圖生視頻Prompt指南

    更新時間：Sep 02, 2026

    在使用萬相進行AI視頻內容創作時，可運用 結構化提示詞公式 ，提升產生視頻的品質與藝術表現力。

    適用範圍：

    • 文生視頻API參考
    • 圖生視頻-首幀生視頻API參考

    提示詞公式

    提示詞（prompt）是指正向提示詞，用來描述視頻中所包含的畫面內容和運動過程，描述越準確、越豐富，產生視頻的品質越高。

    基礎公式

    適用於初次嘗試AI視頻的新使用者，及將AI視頻作為靈感啟發的使用者，簡單自由的提示詞可產生更具有想象力的視頻。

    提示詞 = 主體 + 情境 + 運動

    主體：主體是視頻內容的主要表現對象，可以是人、動物、植物、物品或非物理真實存在的想象物體。

    情境：情境是主體所處的環境，包含背景、前景，可以是物理存在的真實空間或想象出來的虛構情境。

    運動：運動包含主體的具體運動和非主體的運動狀態，可以是靜止、小幅度運動、大幅度運動、局部運動或整體動勢。

    進階公式

    適用於有一定AI視頻使用經驗的使用者，在基礎公式之上添加更豐富細緻的描述可有效提升視頻質感、生動性與故事性。

    提示詞 = 主體（主體描述）+ 情境（情境描述）+ 運動（運動描述）+ 美學控制 + 風格化

    主體描述：主體描述是對主體外觀特徵細節的描述，可通過形容詞或短句列舉，例如“一位身著少數民族服飾的黑髮苗族少女”、“一位來自異世界的飛天仙子，身著破舊卻華麗的服飾，背後展開一對由廢墟片段構成的奇異翅膀”。

    情境描述：情境描述是對主體所處環境特徵細節的描述，可通過形容詞或短句列舉。

    運動描述：運動描述是對運動特徵細節的描述，包含運動的幅度、速率和運動作用的效果，例如“猛烈地搖擺”、“緩慢地移動”、“打碎了玻璃”。

    美學控制：包含光源、光線環境、景別、視角、鏡頭、運鏡等，常見鏡頭語言詳見下方提示詞詞典。

    風格化：風格化是對畫面風格語言的描述，例如“賽博龐克”、“勾線插畫”、“廢土風格”，常見風格化詳見下方提示詞詞典。

    圖生視頻公式

    映像已經確定了主體、情境與風格，因此提示詞主要描述動態過程及運鏡需求。

    提示詞 = 運動 + 運鏡

    運動描述：結合映像中的元素（如人物、動物），描述其相動態過程，如奔跑、打招呼，可以通過形容詞來控制動態程度與速度，如“快速地”、“緩慢地”。

    運鏡：若對鏡頭運動有特定要求，通過提示詞如“鏡頭推進”、“鏡頭左移”控制，若希望鏡頭不要發生變化，可以通過“固定鏡頭”來強調。

    聲音公式（wan3.0/wan2.7/wan2.6/wan2.5）

    基於原生音頻能力，增加對人聲、音效與背景音樂的描述，提高聲音控制能力。

    提示詞 = 主體 + 情境 + 運動 + 聲音描述（人聲/音效/背景音樂）

    聲音描述：聲音描述是視頻中聲音要素及其隨時間變化的描述，用來指導聲音內容和聲音氛圍，使其與畫面敘事精準配合，主要包括人聲、音效、BGM三類。

    人聲 = 角色說話的內容 + 情緒 + 語調 + 語速 + 音色 + 口音

    樣本：一個男人在講脫口秀，他說道："好好學習，天天向上"，語氣輕鬆，語速適中，聲音清亮，美式英文。

    音效 = 音源材質 + 行為 + 環境音

    樣本：一個玻璃小球從案頭掉在木質地面上，發出“砰”的聲音，室內安靜環境。

    背景音樂 = 背景音樂/配樂 + 風格

    樣本：雨夜，陰森窄小的走廊，盡頭有一扇窗戶，配有懸疑風格背景音樂。

    多鏡頭公式（wan3.0/wan2.7/wan2.6）

    萬相2.7和萬相2.6模型支援產生多鏡頭連貫敘事視頻，可通過提示詞精準控制鏡頭結構、機位與時間長度，並確保主體、情境與氛圍等關鍵元素在鏡頭間一致。

    提示詞 = 總體描述 + 鏡頭序號 + 時間戳記 + 分鏡內容

    總體描述：簡要概述整個視頻內容，說明故事主題、敘述風格、主要情感或核心事件，便於AI把握全域敘事方向。

    鏡頭序號：為每個鏡頭分配編號，用於區分視頻中不同的情境或段落順序，協助清晰組織視頻結構。如“鏡頭1 xxxx，鏡頭2 xxxx”或“鏡頭1[0-3秒]xxxx，鏡頭2[3-6秒]xxx”等。

    時間戳記：標明每個鏡頭在視頻中的具體時間範圍，確保鏡頭內容與視頻時間軸對應，提升產生的準確性。

    分鏡內容：詳細描述每個分鏡頭中主要角色或物體的具體行為，包括動作、語言、表情、姿態等，可以參考一般單鏡頭的提示詞寫法。

    樣本：

    這個故事以第三人稱視角，講述了一個關於放棄與重拾希望的短劇。

    第1個鏡頭[0-3秒]一個男孩在操場的角落獨自坐著，低頭望著手中的信紙，隨後輕輕歎氣，眼神中透露出迷茫。

    第2個鏡頭[4-6秒]硬切轉場，固定機位，聚焦於男孩的眼睛，淚光閃爍，帶著失落和無助。

    第3個鏡頭[7-10秒]硬切轉場，情境轉至一間簡樸的教室。一個女孩眼神溫和而堅定，穿著樸素的衣著，面帶溫和而堅定的笑容，走到男孩的身邊安慰他。

    單鏡頭說明：wan2.7模型不再支援shot_type指定單鏡頭/多鏡頭，而是由模型結合提示詞進行發揮。如果想控制多鏡頭，參考上述提示詞寫法；如果想控制一鏡到底，則中文寫為“產生單鏡頭”，英文寫為“Generate single shot.”

    參考生視頻公式（wan3.0/wan2.7/wan2.6）

    萬相2.7和萬相2.6模型支援參考映像或視頻產生視頻，可參考主體的外觀形象、動態特徵和音色（如有），還支援參考背景。主體類型不限，包括人物、卡通、寵物或道具等。

    wan3.0/wan2.7

    提示詞 = 參考指代 + 動作 + 情境 + 台詞（可選）+ 背景音樂（可選）

    參考指代：使用“圖n”或“視頻n”在提示詞中指代參考檔案，n為該檔案在該類型中的序號。圖和視頻分別計數。

    參考素材類型+序號：參考圖片時寫為“圖n”，視頻時寫為“視頻n”，如有三張圖時，分別為圖1、圖2、圖3，序號與上傳順序一致，圖和視頻分開計數。若只有一個參考時，序號可不寫，簡化為“參考圖片”或“參考視頻”。

    中英文寫法：中文寫為“圖1”、“視頻1”，英文寫為“Image 1”、“Video 1”。英文字母和數字之間有空格，首字母大寫。

    畫面內容描述：假設參考圖1是一隻貓，圖2是一個房間，則描述貓在房間裡玩耍，支援兩種寫法：①直接寫參考指代，如“圖1在圖2裡玩耍”；②寫參考指代+物體/情境，如“圖1的貓在圖2的房間裡玩耍”。

    動作：描述主體或其他元素的運動狀態，包括靜止、表情情緒變化、肢體動作、外力動作和位移變化等。

    情境：主體所在的環境，包括背景和前景，既可以是真實空間，也可以是虛構情境。

    台詞：主體的說話內容。在提示詞中描述到台詞內容時，如xx說：“xxx”，模型會保持該台詞內容不變進行產生。若提示詞中未描述台詞，則模型會自由發揮添加台詞。若想控制不要有台詞，中文寫為“無台詞”，英文寫為“No dialogue.”

    背景音樂：當提示詞不描述背景音樂時，模型會根據題材和內容自行發揮。如果不想要背景音樂，中文寫為“無背景音樂”，英文寫為“No background music.”。

    樣本1：視頻2抱著圖3在咖啡廳裡彈奏一支舒緩的美式鄉村民謠，視頻1笑著看著視頻2。

    其中，視頻1指代的參考視頻是一個女性，視頻2指代的參考視頻是一個男性，圖3指代的參考映像是一把吉他。

    wan2.6

    提示詞 = 主角 + 動作 + 台詞 + 情境

    主角：通過“character1”等標識引用參考主角，最多可同時參考3個主角，每個主角可在提示詞中多次引用，實現對其行為的精準控制。

    動作：描述主角或其他元素的運動狀態，包括靜止、表情情緒變化、肢體動作、外力動作和位移變化等。

    台詞：主角的說話內容，支援單主角說話或多主角對話。

    情境：主角所在的環境，包括背景和前景，既可以是真實空間，也可以是虛構情境。

    樣本：這是一個充滿童趣的童話情境。character1在草地上蹦跳著玩耍，character2在旁邊的一顆蘋果樹下彈奏鋼琴，一顆蘋果掉到了character2的頭上，character1開心地指著character2說：“你要變成科學家了！”。

    其中，character1的參考視頻是一隻兔子，character2的參考視頻是一隻狗，且每個參考視頻僅包含單一角色。

    提示詞最佳化技巧

    1. 自動最佳化：啟用 prompt_extend 參數

    在調用 API 時可啟用 prompt_extend 參數，系統將自動對輸入的正向提示詞進行智能最佳化與改寫。該功能對簡短、寬泛的提示詞（如“小貓在雪地裡玩雪球”），提升效果較好。

    2. 通過提示詞公式產生提示詞

    當需要精準控制畫面細節、風格或複雜動態時，推薦採用結構化提示詞公式進行編寫。

    您可以將上述公式作為系統訊息（system message）提供給大語言模型（如 qwen3.6-plus），產生結構清晰的提示詞。

    樣本：使用聲音公式最佳化提示詞

    更多範例程式碼詳見概述。

    輸入樣本
    import os
from openai import OpenAI

try:
    client = OpenAI(
        # 新加坡和北京地區的API Key不同。擷取API Key：https://www.alibabacloud.com/help/zh/model-studio/get-api-key
        # 若沒有配置環境變數，請用阿里雲百鍊API Key將下行替換為：api_key="sk-xxx",
        api_key=os.getenv("DASHSCOPE_API_KEY"),
        # 以下為新加坡地區配置，調用時請將WorkspaceId替換為真實的業務空間ID，各地區的配置不同。
        base_url="https://{WorkspaceId}.ap-southeast-1.maas.aliyuncs.com/compatible-mode/v1",
    )

    completion = client.chat.completions.create(
        # 模型列表：https://www.alibabacloud.com/help/zh/model-studio/models
        model="qwen3.6-plus",
        messages=[
            {"role": "system", "content": "你是一個提示詞最佳化助手，提示詞公式為：提示詞 = 主體 + 情境 + 運動 + 聲音描述（人聲/音效/背景音樂）\n聲音描述：聲音描述是視頻中聲音要素及其隨時間變化的描述，用來指導聲音內容和聲音氛圍，使其與畫面敘事精準配合，主要包括人聲、音效、BGM三類。\n人聲 = 角色說話的內容 + 情緒 + 語調 + 語速 + 音色 + 口音\n樣本：一個男人在講脫口秀，他說道：“好好學習，天天向上”，語氣輕鬆，語速適中，聲音清亮，美式英文。\n音效 = 音源材質 + 行為 + 環境音\n樣本：一個玻璃小球從案頭掉在木質地面上，發出“砰”的聲音，室內安靜環境。\n背景音樂 = 背景音樂/配樂 + 風格\n樣本：雨夜，陰森窄小的走廊，盡頭有一扇窗戶，配有懸疑風格背景音樂。"},
            {"role": "user", "content": "小貓在雪地裡玩雪球"},
        ],
    )
    print(completion.choices[0].message.content)
    # 如需查看完整響應，請取消下列注釋
    # print(completion.model_dump_json())
except Exception as e:
    print(f"錯誤資訊：{e}")
    print("請參考文檔：https://www.alibabacloud.com/help/zh/model-studio/error-code")
    輸出樣本

情境：冬日清晨的雪地，銀裝素裹的庭院，積雪厚實鬆軟，周圍有結霜的樹枝和遠處堆好的小雪人

- 人聲：無
- 音效：小貓爪子踩在雪地上發出“咯吱咯吱”的輕響；雪球滾動時雪粒摩擦的“沙沙”聲；雪球破裂時“哢啦”一聲；小貓打噴嚏“阿嚏！”清脆可愛；翻滾時積雪掉落的“簌簌”聲
- 背景音樂：輕快溫馨的鋼琴配樂，帶有童謠風格，節奏跳躍如小動物嬉戲，營造冬日童趣氛圍
