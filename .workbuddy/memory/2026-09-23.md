### 怎么进去的（可复用路径）

`mcp.liblib.tv/mcp` 的 OAuth 是 **2.1 授权码 + PKCE + 动态客户端注册**，流程：

1. `POST /register`（DCR）→ 201，拿 `client_id` + `client_secret`（secret 约 90 天有效）
2. 组 `authorize` URL（带 `code_challenge` S256、`state`、`resource=https://mcp.liblib.tv/mcp`）→ 浏览器授权
3. 本地 `127.0.0.1:8765` 收 code → `POST /token`（form，带 `client_secret` + `code_verifier`）→ 200
4. `POST /mcp` 带 Bearer → `initialize` → `tools/list`

脚本全在 `.tmp\mcp_probe\`（`step_a_register.py` / `step_b_probe.py` / `step_c_readonly.py` / `step_e_caps.py` / `step_g_preflight.py`）。**无需 session id**（服务端无状态，`Mcp-Session-Id` 返回 None）。
